# 野外魔王規格（美術與程式的共同契約）

靈感：楓之谷的巴洛古、殘暴炎魔、蘑菇王——在狩獵地圖定時出現的魔化巨獸，暗黑奇幻、壓迫感強，跟可愛的一般怪形成反差。
故事：星楓葉的力量滿溢出來，侵蝕最深的那隻生物「魔化」了。外型一律要有：魔化的發光裂紋、犄角或骨刺、發光的眼睛、壓倒性的體型（約一般怪的 3 倍）。
每章一隻，第二階段（血量 ≤ 50%）外型「暴走」：裂紋更亮、翅膀／火焰／冰晶張開、顏色加深。

## 資料與出現規則（程式）
- 資料：js/data/fieldboss.js，放進 G.data.monsters，`fieldBoss: true`、`band: true`（等級不被重新對應），`fallback` 借用舊美術。
- 每隻綁一張狩獵地圖。玩家在那張地圖上、而且冷卻已過（遊戲時間 6 分鐘，存在 world.flags 或存檔裡）時，在離玩家至少 500px 的地面平台上出現。
  出現時：畫面震動、音效、中央大字「⚠ 深淵菇魔 出現了！」；離開地圖就消失（下次再來重新出現、滿血）。
- 畫面上方顯示魔王血條（名字、等級、血量），第二階段血條變紅並閃一下。
- 數值：血量約同等級一般怪的 25 倍、攻擊 1.3 倍；經驗約 25 隻一般怪；金幣 20 倍；必掉 1 件史詩以上的裝備＋2～3 瓶大紅／大藍；一般怪的包圍減傷照常。
- 招式都有 0.8～1.5 秒的預警（地上發亮的範圍、蓄力姿勢），不秒人；打倒時大爆炸、慢動作 0.3 秒。
- 能力掛在 G.mobAbil（寫法同 js/game/mobabil.js）。

## 繪圖契約
同 docs/SPEC-monsters.md：`A.MONSTER_DRAW[art] = fn(ctx, m)`，原點腳底、面向右、`A.c()` 上色、save/restore 成對（**不能多 restore**，圖鑑會錯位）。
投射物與地面區域：`A.PROJ_DRAW` / `A.ZONE_DRAW`，寫法同 js/art/monsters3.js。
