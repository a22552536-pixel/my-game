# 怪物規格 v2（第二～終章）——美術與程式的共同契約

## 設計原則（使用者定案）
自然物（動物／植物／自然現象）＋ 一個**劍與魔法的奇幻概念**（魔法、武器、鎧甲、符文、咒語、卷軸、水晶、法陣、元素……）。
**不要**現實日常用品（郵筒、燈泡、鬧鐘、積木、手風琴……）。疊上去的概念和原本靈感沒有關聯，而且**會變成行為**。
越後面越大、越抽象：第二章約為第一章的 1.15 倍、第三章 1.3 倍、第四章 1.45 倍、終章 1.6 倍（時間、空間魔法）。

## 繪圖契約（所有怪物美術檔共用）
- 註冊：`Object.assign(G.art.MONSTER_DRAW, { <art>: fn })`，`fn(ctx, m)`。原點在腳底中央，面向右（翻轉由 `A.drawMonster` 處理），身體約佔 `m.w × m.h`，往上是負 y。
- 風格同 js/art/monsters2.js：平塗、深棕描邊（`A.shape` / `A.outline`）、右下月牙陰影、左上亮點、可愛但有特色的眼睛。顏色一律用 `A.c(color)`（閃白、剪影、染色才會正常），畫完還原 canvas 狀態（save/restore）。
- 動畫：`m.t`（秒）、`m.state`（'walk'/'idle'）、`m.attackPhase`（'wind'/'strike'/'recover'/null）、`m.hurtT > 0` 被打中。
- `m.fx` 是能力的表現旗標，可能缺欄位，一律給預設值。
- 飛行怪：`m.hover` 是離地高度，`A.drawMonster` 已經往上平移，照常以腳底為原點畫（可以不畫腳）。
- 投射物：`Object.assign(G.art.PROJ_DRAW, { <kind>: fn })`，寫法照 js/art/monsters3.js 既有的 letter/note。
- 地面區域：`Object.assign(G.art.ZONE_DRAW, { <kind>: fn })`，寫法照 js/art/monsters3.js 的 ink、monsters4.js 的 quake。
- 材料圖示：`A.ICON[<材料id>]`，寫法照 monsters3.js 結尾。

# v1.4 重新設計（使用者回饋：細緻度要提高；越後面的章節越不要用日常動物，改用神話生物）

原則：第一章不動（入門章）。第二、三章保留「動物＋奇幻概念」但細緻度大幅提高。第四章、終章改成**神話生物**，
**id、體型、能力、m.fx 旗標、投射物與地面區域 kind 全部不變**，只換外觀、名字、材料名。
細緻度目標：比一般 Q 版小怪精緻很多（層次、陰影、發光、配件細節、有個性的輪廓），但不用到 Boss 的程度。
使用者點名做得差的：綿羊、封印狐、袋鼠、符兔、平行狐、蛇（銜尾蛇）、時停蝶（概念好但醜）；做得好的：星座魚（不動）。
